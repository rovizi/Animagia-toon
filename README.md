# Animagia Toon API

API desenvolvida em FastAPI para gerenciamento do catálogo de animações do projeto **Animagia**.

## Funcionalidades
- Gerenciamento das temporadas do *Chaves em Desenho*.
- Endpoints prontos para integração com o frontend.

## Tecnologias
- Python 3.x
- FastAPI
- SQLAlchemy
- SQLite

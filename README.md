# Animagia Toon API 🎬

API desenvolvida em **FastAPI** e **SQLAlchemy** (hospedada no Render) para exibição de cards interativos de desenhos animados clássicos, contendo player de vídeo integrado embutido e sinopses detalhadas.

## 📺 Conteúdo em Destaque
* **Desenho:** Pica-Pau Clássico
* **Temporada / Formato:** Mega Compilação • 38 Episódios
* **Classificação Indicativa:** Livre

## 🚀 Tecnologias Utilizadas
* **Python / FastAPI:** Estrutura e rotas da API.
* **SQLAlchemy:** Persistência e gerenciamento do banco de dados para os metadados dos desenhos.
* **HTML5 / CSS3 / JavaScript:** Interface do card responsivo com player dinâmico integrado (sem redirecionamentos externos).

---
*Projeto desenvolvido para centralizar entretenimento animado de forma fluida e sem bloqueios de reprodução.*
